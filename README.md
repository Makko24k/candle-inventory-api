# Scented Candle Inventory and Raw Materials Tracking System

Backend prototype for ITEC 116 (Systems Integration and Architecture 2).
It tracks raw materials, suppliers, candle products, recipes, and production logs.

## Tech Stack
NestJS, TypeORM, MySQL, JWT, Postman

## How to Run
1. Start MySQL in XAMPP and create a database named `candle_inventory`.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and fill in your database settings.
4. Run `npm run start:dev`.
